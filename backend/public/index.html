📚 RAG API 文档

基于检索增强生成的智能文档问答系统 API 参考

🏥

健康检查

GET /health

检查服务器健康状态和运行状态

响应示例：
{ "status": "OK", "timestamp": "2024-01-01T12:00:00.000Z", "service": "RAG Backend" }
❓

智能问答

POST /api/qa/ask

向文档提问并获取AI回答（支持RAG检索）

参数 类型 必填 描述
question string 是 要提问的问题
documentId string 否 指定文档ID（可选，不指定则搜索所有文档）
topK number 否 返回的最相关片段数量（默认：5）
请求示例：
{ "question": "这个文档的主要观点是什么？", "documentId": "507f1f77bcf86cd799439011", "topK": 3 }
响应示例：
{ "question": "这个文档的主要观点是什么？", "answer": "文档主要讨论了人工智能在金融领域的应用...", "contexts": [ { "text": "人工智能技术正在彻底改变金融服务行业...", "score": 0.92, "metadata": {} } ], "timestamp": "2024-01-01T12:00:00.000Z" }
POST /api/qa/batch-ask

批量处理多个问题（最多10个）

参数 类型 必填 描述
questions string[] 是 问题数组
documentId string 否 指定文档ID
topK number 否 返回的最相关片段数量（默认：3）
GET /api/qa/capabilities

获取问答系统的能力和配置信息

响应示例：
{ "capabilities": { "supportsMultipleDocuments": true, "maxContextLength": 4000, "supportedFormats": ["pdf", "docx", "txt"], "maxBatchSize": 10, "ragEnabled": true }, "available": true, "timestamp": "2024-01-01T12:00:00.000Z" }
POST /api/qa/search

在文档中进行语义搜索

参数 类型 必填 描述
query string 是 搜索查询
documentId string 否 指定文档ID
topK number 否 返回的最相关结果数量（默认：10）
📄

文档管理

GET /api/documents

获取文档列表（支持分页和过滤）

参数 类型 必填 描述
page number 否 页码（默认：1）
limit number 否 每页数量（默认：10）
status string 否 过滤状态：ready/processing/error
fileType string 否 文件类型过滤
GET /api/documents/:id

根据ID获取单个文档详情

GET /api/documents/:id/content

获取文档的完整文本内容

DELETE /api/documents/:id

删除指定文档（同时删除向量索引）

GET /api/documents/stats/summary

获取文档统计信息

GET /api/documents/search/text

在文档标题和内容中进行文本搜索

参数 类型 必填 描述
q string 是 搜索关键词
page number 否 页码（默认：1）
limit number 否 每页数量（默认：10）
📤

文件上传

POST /api/upload

上传文档文件（支持PDF、DOCX、TXT格式）

参数 类型 必填 描述
document file 是 要上传的文件
title string 否 文档标题（默认使用文件名）
description string 否 文档描述
userId string 否 用户ID（测试用途）
响应示例：
{ "message": "Document uploaded successfully", "document": { "id": "507f1f77bcf86cd799439011", "title": "示例文档", "filename": "1234567890.pdf", "originalName": "example.pdf", "fileType": "pdf", "fileSize": 1024000, "status": "processing", "uploadedAt": "2024-01-01T12:00:00.000Z" } }
GET /api/upload/status/:documentId

获取文件上传和处理状态

🔍

索引管理

POST /api/indexing/index-docs

开始索引docs目录中的所有文档（后台任务）

GET /api/indexing/indexing-status

获取索引任务状态

👤

用户认证

POST /api/auth/register

注册新用户

参数 类型 必填 描述
username string 是 用户名
email string 是 邮箱地址
password string 是 密码
role string 否 用户角色（默认：user）
POST /api/auth/login

用户登录

参数 类型 必填 描述
email string 是 邮箱地址
password string 是 密码
GET /api/auth/profile

获取用户资料信息

参数 类型 必填 描述
userId string 是 用户ID（查询参数）
POST /api/auth/verify

验证JWT Token有效性

参数 类型 必填 描述
token string 是 JWT Token
